# Apoloplex

A forthcoming five-panel satirical comic series set in a theme park where Christian apologists meet curious crowds.

Website: https://apoloplex.com/

This public repository contains the placeholder page and its selected artwork. GitHub Pages serves the root of the main branch. The page is plain HTML, CSS and JavaScript and needs no build step or external dependencies.

The preview starts in grayscale; its watercolor companion uses the same drawing. All conversations in the planned series are fictional satire unless explicitly identified otherwise.

Artwork was made with OpenAI's built-in image generator and locally finished for the Apoloplex project. By Phil Stilwell.
