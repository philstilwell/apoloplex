# Apoloplex

A philosophical comic series for readers of Christian apologetics, skepticism and philosophy of religion. Fictional theme-park conversations examine premises, evidence, substantive objections and what follows.

Website: https://apoloplex.com/

Each episode uses as many images as its point requires. Existing character sheets and park establishing views keep their reference formats.

The site introduces eight apologist caricatures, creator Phil as a questioning park visitor, and eight theme park attractions. Open a portrait for a character sheet with three poses, six expressions and an imagined encounter. Open a park scene to browse the artwork at a larger size. The viewer supports Previous/Next buttons, arrow keys and Escape.

Characters and author credits use first names throughout the site, including labels printed inside the artwork.

The public site uses color artwork throughout: all nine character portraits, their model sheets, park scenes and comic images, including enlarged views. Matching grayscale masters remain in the private production library for print.

GitHub Pages serves the root of the main branch. The site uses plain HTML, CSS and JavaScript, with no external runtime dependencies. Gallery links open the artwork directly if JavaScript is unavailable. Artwork below the opening scene loads as visitors scroll. The layout adapts to narrower screens.

All character roles and park encounters are fictional satire, not quotations or reports of actual encounters. No affiliation or endorsement is implied.

Artwork was made with OpenAI's built-in image generator and locally finished for the Apoloplex project. By Phil.

## Comics

[Browse all comics](https://apoloplex.com/#comics), covering fine-tuning, faith and evidence, the burden of proof, religious knowledge, petitionary prayer and theological explanation. Each scene has a dialogue transcript and deeper analysis; each complete strip ends with an extended skeptical argument addressing objections and limits.

Readers can enlarge and zoom the images, navigate scenes with arrow keys and read descriptions and dialogue transcripts. Episode images use lossless WebP. Episode metadata is in assets/comics/catalog.json; presentation and controls are in reader.css and reader.js.

Every published page includes a unique search title and description, its canonical address, sharing previews and structured descriptions of the comic series. The [sitemap](https://apoloplex.com/sitemap.xml) lists published pages and artwork and is advertised in robots.txt. All dialogue and analysis are available in the page HTML without requiring JavaScript.
