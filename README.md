# Apoloplex

A five-panel satirical comic series set in a theme park where Christian apologists meet curious crowds.

Website: https://apoloplex.com/

The site introduces eight apologist caricatures and eight theme park attractions. Open a portrait for a character sheet with three poses, six expressions and an imagined encounter. Open a park scene to browse the artwork at a larger size. The viewer supports Previous/Next buttons, arrow keys and Escape.

Every page load starts in grayscale. The Watercolor controls change all eight character portraits, their full model sheets and all park scenes together, including the enlarged view. The approved grayscale originals remain the default. The park's two editions share the same composition. Grayscale exports are checked for equal red, green and blue channels.

GitHub Pages serves the root of the main branch. The site uses plain HTML, CSS and JavaScript, with no external runtime dependencies. Gallery links open the artwork directly if JavaScript is unavailable. Artwork below the opening scene loads as visitors scroll. The layout adapts to narrower screens.

All character roles and park encounters are fictional satire, not quotations or reports of actual encounters. No affiliation or endorsement is implied.

Artwork was made with OpenAI's built-in image generator and locally finished for the Apoloplex project. By Phil Stilwell.
